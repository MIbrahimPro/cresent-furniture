# Crescent Brand Assets

Vector masters and generated exports extracted from `branding/index.html`.

## Folders

- `logo/`: full lockups and the compact monogram in SVG format.
- `png/`: high-resolution logo and social exports.
- `favicon/`: favicon SVG, PNG sizes, and ICO.
- `fonts/`: locally downloaded font files used by the brand system.

SVG files remain the source of truth. They use the brand palette and request Cinzel with Georgia/Times fallbacks when opened without local web fonts.
