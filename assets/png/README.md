# Crescent PNG Exports

These PNGs are raster exports of the SVG masters in `../logo/`.

## Files

- `crescent-logo-maroon-2000.png` - primary logo on a `#3D141E` rounded tile, 2000 x 720.
- `crescent-logo-light-2000.png` - transparent light-background version, 2000 x 720.
- `crescent-logo-on-maroon-2000.png` - transparent version with cream descriptor for dark surfaces, 2000 x 720.
- `crescent-avatar-1000.png` - monogram avatar, 1000 x 1000.
- `crescent-og-1200x630.png` - maroon Open Graph image with centered lockup, 1200 x 630.

## Export guidance

Use these files for websites, presentations, social media, and other raster-only workflows. Use the SVG masters for print, signage, embroidery, and any artwork that may be resized.

The wordmark and descriptor are rendered with the supplied Cinzel font files and explicit character spacing so every letter remains intact at export time. Do not re-save through a tool that substitutes fonts or removes transparency.
