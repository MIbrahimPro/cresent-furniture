04 · Typography

    
Classical caps, quiet serif

    
The sign uses a Trajan-style Roman capital face. The free web equivalent is Cinzel (Google Fonts, SIL Open Font License — free for commercial use). Body text pairs with EB Garamond for an old-world, workshop feel.


    

      

        
Aa

        
Cinzel — Display & UI

        
Wordmark, headings, buttons, nav, labels. Always uppercase with tracking.

        
  • Weights: 400 / 500 / 600 / 700
  • Tracking: .04em headings · .18em buttons · .3em eyebrows
  • Fallback: Georgia → “Times New Roman” → serif
  • Paid alternative (exact sign font): Trajan Pro

      

      

        
Aa

        
EB Garamond — Body

        
Paragraphs, product descriptions, captions, quotes.

        
  • Weights: 400 / 500 / 600 + italic
  • Line-height 1.65 · max measure 68 characters
  • Fallback: Georgia → serif

05 · Buttons & Interaction

    
Primary & secondary actions

    
Sharp 3 px corners, letterspaced Cinzel caps, 48 px tall. The primary is the only place big blocks of coral are allowed — deep-maroon text on coral passes AA contrast. Hover = darken + 1 px lift. No gradients, no pills.

06 · Website Recipe

    
Building the site

    
Cream canvas, maroon anchor sections, coral used sparingly. Copy the design tokens below and the whole site stays on-brand by default.


    
:root{
  /* brand colors */
  --maroon:#3D141E;      /* primary background */
  --maroon-deep:#2A0D14; /* footer, hovers, scrims */
  --coral:#E5624D;       /* accent, CTA, links */
  --coral-dark:#C44A38;  /* coral hover / small text */
  --coral-tint:#F8DAD0;  /* soft fills */
  --cream:#FAF5EC;       /* light background */
  --parchment:#F2E9DB;   /* alternate section bg */
  --ink:#2B1B20;         /* body text on light */
  --muted:#7A666C;       /* secondary text */
  --line:rgba(61,20,30,.14);
  /* type */
  --font-display:"Cinzel",Georgia,"Times New Roman",serif;
  --font-body:"EB Garamond",Georgia,serif;
  /* shape & depth */
  --radius:3px; --radius-card:6px;
  --shadow-sm:0 1px 2px rgba(42,13,20,.08);
  --shadow-md:0 8px 24px rgba(42,13,20,.12);
  --shadow-lg:0 16px 40px rgba(42,13,20,.16);
  /* motion */
  --ease:cubic-bezier(.2,.7,.3,1); --fast:200ms;
}
